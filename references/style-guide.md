# 风格参考指南

详细的视觉特征、参考样图描述、关键词库，供生成提示词时参考。

## 1. 极简清新（minimalist-clean）

**视觉特征**：
- 纯白或奶白底色（#FFFFFF / #FAF7F2）
- 产品居中，构图极简
- 大标题加粗，字号大但占位克制
- 留白丰富，呼吸感强
- 一道柔和侧光，无强烈对比

**关键词库**：
```
minimalist, clean composition, soft side light, pure white background,
product photography, simple, breath of space, sans-serif typography,
negative space, contemporary
```

**中文风格补充**：
```
极简，纯白底色，柔和光线，呼吸感，留白
```

**典型应用**：Apple 产品、设计师品牌、香薰、首饰、文具

---

## 2. ins平铺风（ins-flatlay）

**视觉特征**：
- 俯拍 90° 视角
- 大理石桌面 / 亚麻布 / 浅色木桌
- 产品 + 配件整齐平铺
- 周围点缀道具：咖啡杯、耳机线、口红、书本、眼镜、杂志
- 自然光从侧面打入

**关键词库**：
```
flat lay photography, top-down view, marble table background,
lifestyle props, instagram aesthetic, natural light, soft shadows,
organized arrangement, neutral tones
```

**中文风格补充**：
```
ins 风，俯拍，平铺，大理石，自然光，生活道具
```

**典型应用**：美妆、首饰、相机、香水、文创周边

---

## 3. 日系复古（vintage-japanese）

**视觉特征**：
- 暖黄、橙红调色
- 轻微胶片颗粒感
- 柔和高光、轻微过曝
- 静物摄影感
- 常见于：胶片相机、黑胶唱片机、复古收音机、手账本

**关键词库**：
```
japanese vintage style, film photography, warm tones, kodak portra,
soft overexposure, nostalgic, retro aesthetic, 90s japanese lifestyle
```

**中文风格补充**：
```
日系复古，胶片质感，暖色调，怀旧，文艺
```

**典型应用**：胶片相机、黑胶、复古音响、手作服本、vintage 服饰

---

## 4. 国潮水墨（guochao-ink）

**视觉特征**：
- 红 + 黑 + 金配色
- 水墨晕染笔触
- 毛笔字标题
- 朱红印章
- 祥云/水墨山水/留白意境

**关键词库**：
```
chinese ink painting, red and black color scheme, gold accents,
calligraphy, traditional chinese aesthetic, oriental elements,
rice paper texture, stamp seal, brush strokes
```

**中文风格补充**：
```
国潮，水墨，红黑金，毛笔字，印章，传统美学
```

**典型应用**：茶具、文玩、汉服、瓷器、茶叶、文房四宝

---

## 5. 科技质感（modern-tech）

**视觉特征**：
- 深色背景（深蓝/深紫/纯黑）
- 产品悬浮，镜面地面反射
- 紫色/青色辉光边缘
- 镜面金属质感
- 数据流、粒子、几何线条

**关键词库**：
```
dark background, blue purple neon glow, floating product,
tech aesthetic, mirror reflection, sci-fi lighting, cyberpunk,
metallic surface, rim light
```

**中文风格补充**：
```
科技感，深色背景，霓虹辉光，悬浮，镜面反射，赛博朋克
```

**典型应用**：手机、笔记本、平板、耳机、智能手表、键盘

---

## 6. 温馨日常（warm-daily）

**视觉特征**：
- 木质桌面（暖色系）
- 暖黄光、自然窗光
- 真实生活场景（茶几、床头柜、沙发边）
- 旁边点缀生活用品
- 微距景深

**关键词库**：
```
cozy home interior, warm natural light, wooden table, lifestyle,
lived-in feel, bokeh, morning light, comfortable atmosphere
```

**中文风格补充**：
```
温馨家居，暖光，木质桌面，生活感，景深
```

**典型应用**：家居、母婴、家电、书籍、小家电、织物

---

## 7. Y2K 千禧风（y2k-pop）

**视觉特征**：
- 银白/霓虹粉/电光蓝/亮面质感
- 镭射全息、CD纹
- 金属反光、镜面
- 复古电子元素
- 2000年代未来感

**关键词库**：
```
y2k aesthetic, holographic, iridescent, chrome, metallic,
neon pink, electric blue, 2000s nostalgia, cyber futurism
```

**中文风格补充**：
```
Y2K，千禧风，镭射，金属感，霓虹，2000年代
```

**典型应用**：潮玩、Y2K配饰、复古电子、银饰、透明配饰

---

## 8. 可爱贴纸风（cute-sticker）

**视觉特征**：
- 手绘涂鸦、表情包
- 卡通图标、五彩边框
- 大色块、糖果色
- 童趣、活泼、亲切感
- 装饰性符号如 ❤ ✨ ★

**关键词库**：
```
cute illustration, hand-drawn doodles, sticker style, playful,
colorful borders, kawaii, cartoon icons, candy colors, cheerful
```

**中文风格补充**：
```
可爱风，手绘，贴纸，卡通，糖果色，童趣
```

**典型应用**：母婴、玩具、文具、儿童用品、宠物用品

---

## 9. 杂志编辑风（editorial-magazine）

**视觉特征**：
- 大面积留白
- 高级灰 / 中性色
- 纤细字体、衬线字
- 人物 + 产品组合
- 摄影质感突出
- 印刷品质感

**关键词库**：
```
editorial photography, magazine cover, sophisticated, fashion,
designer brand, negative space, refined typography, muted tones,
high-end aesthetic, fashion model
```

**中文风格补充**：
```
杂志感，编辑摄影，时尚，高级灰，留白，精致
```

**典型应用**：设计师服饰、奢侈品、设计师首饰、设计师家居
